# AT710 Android App

Начальное Android-приложение для проверки, видит ли телефон титратор KEM AT-710 как USB-устройство.

## Что умеет первая версия
- показывает USB-устройства, обнаруженные Android;
- выводит Vendor ID, Product ID и сведения об интерфейсах;
- запрашивает разрешение Android на USB-доступ;
- проверяет, удаётся ли открыть USB-устройство.

**Важно:** это диагностическая заготовка. Она не реализует протокол KEM AT-710 и пока не считывает результаты титрования.

## Сборка APK
При каждом push в `main` или запуске вручную в GitHub Actions workflow `Build Android APK` собирает debug APK. Откройте вкладку Actions, выберите успешный запуск и скачайте артефакт `AT710-debug-apk`.
